# Запали Кристал чисел

Інтерактивна гра для онлайн-уроку «Змінні» (Minecraft MakeCode, 8 років).

Відкрийте `index.html` подвійним кліком — збирати нічого не треба.
Керує грою вчитель (демонстрація екрана):

- **Пробіл** — показати відповідь, а якщо вона вже показана — далі
- **H** — підказка
- **←** / **→** — назад / далі

Усі тексти, завдання, підказки й програми раундів зібрані в об'єкті `ROUNDS` на початку скрипта в `index.html`.
